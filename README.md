# Seraphine News Bot

Бесплатный бот, который проверяет Reddit, RSS-новости про LoL и Twitter (через Nitter)
на упоминания Seraphine и присылает находки в Telegram. Работает 24/7 бесплатно
через GitHub Actions — без сервера и без оплаты.

## Шаг 1. Создать Telegram-бота

1. В Telegram напишите **@BotFather** → команда `/newbot`.
2. Придумайте имя, получите **токен** вида `123456789:AAExxxxx...` — сохраните его.
3. Напишите своему новому боту любое сообщение (просто "привет"), чтобы он вас "увидел".
4. Узнайте свой `chat_id`: откройте в браузере
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
   и найдите там `"chat":{"id": ЧИСЛО, ...}` — это и есть ваш chat_id.

## Шаг 2. Загрузить проект на GitHub

1. Создайте новый **приватный** репозиторий на github.com (например `seraphine-bot`).
2. Загрузите туда все файлы из этой папки (можно просто перетащить в веб-интерфейсе
   GitHub, или через git).

## Шаг 3. Добавить секреты

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**

Добавьте два секрета:
- `TELEGRAM_BOT_TOKEN` — токен бота из Шага 1
- `TELEGRAM_CHAT_ID` — ваш chat_id из Шага 1

## Шаг 4. Готово

GitHub Actions сам будет запускать `main.py` каждые 15 минут (расписание в
`.github/workflows/watch.yml`), бесплатно (лимит для приватных репозиториев — 2000
минут в месяц, этого более чем достаточно для проверки раз в 15 минут).

Можно также запустить вручную: вкладка **Actions** в репозитории → workflow
"Seraphine News Watcher" → **Run workflow**.

## Настройка

Открой `main.py` и поменяй под себя:

- `KEYWORDS` — ключевые слова для поиска.
- `TWITTER_ACCOUNTS` — список твиттер-аккаунтов, за которыми следим (лики,
  датамайнеры, эсспорт-аккаунты и т.д.).
- `RSS_FEEDS` — можно добавить любые RSS-фиды других LoL-сайтов.
- `MAX_MESSAGES_PER_RUN` — сколько сообщений максимум слать за один прогон.

## Важно про Twitter

Официальный поиск твитов через API Twitter/X теперь платный (от ~$100/мес),
бесплатного полного доступа больше нет. Скрипт обходит это через публичные
**Nitter-зеркала** (читают твиты без ключей API), но эти зеркала иногда
закрываются или блокируются самим Twitter — это не баг кода, а ограничение
самого Twitter в 2026 году. Если все зеркала из списка `NITTER_INSTANCES`
недоступны, поищите в интернете актуальный публичный список Nitter-инстансов
(например на https://status.d420.de/) и замените адреса в коде.

Поэтому в боте дополнительно подключены Reddit и RSS с фан-сайтов — по опыту,
лики и датамайн там часто появляются так же быстро, а эти источники стабильнее.

## Выход скина прямо в игре (самое важное уведомление)

Бот отдельно проверяет официальные открытые данные Riot — **Data Dragon**
(`ddragon.leagueoflegends.com`) — это те же данные, которые использует сам
клиент League of Legends. В отличие от слухов из Twitter/Reddit, тут не может
быть ложной информации: если скин появился в этих данных — значит, патч
реально выкатился и скин доступен в игре.

Как только у Seraphine появляется новый скин, бот пришлёт вам:
- название скина,
- картинку (сплэш-арт) прямо из официальных ассетов Riot,
- время обнаружения по МСК,
- версию патча.

**Важно:** при самом первом запуске бот не будет спамить про все уже
существующие скины Seraphine — он один раз "запомнит" текущий список и
дальше будет писать только про по-настоящему новые.

## Изменение расписания

В файле `.github/workflows/watch.yml` строка
`cron: "*/15 * * * *"` — можно поменять на `"*/5 * * * *"` (каждые 5 минут)
и т.д. Учтите лимит бесплатных минут GitHub Actions.
